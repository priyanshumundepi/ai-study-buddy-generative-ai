📚 AI Study Buddy — Generative AI Project

An AI-powered learning assistant built using Python, Streamlit, and Google Gemini AI to make studying easier, smarter, and more interactive.

🚀 Project Overview

AI Study Buddy is a Generative AI application designed to help students understand topics, prepare study notes, practice MCQs, and revise concepts using AI-generated flashcards.

✨ Key Features

- 📚 AI Study Notes: Generate organized notes with important concepts and examples.
- 📝 MCQ Quiz: Practice multiple-choice questions, check scores, and review explanations.
- 💡 Topic Explainer: Understand difficult concepts in simple English.
- 🗂️ AI Flashcards: Revise important questions and answers quickly.
- 🎨 Professional UI: An attractive dashboard built with Streamlit.

🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- Google Gen AI SDK
- Google Colab

⚙️ How It Works

1. Enter a study topic.
2. Select a learning tool.
3. Generate AI-powered learning material.
4. Practice, review, and revise the generated content.

💻 Run Locally

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL
cd ai-study-buddy-generative-ai

Replace "YOUR_GITHUB_REPOSITORY_URL" with your actual repository URL.

2. Install dependencies

pip install streamlit google-genai

3. Configure your Gemini API key

Set the "GEMINI_API_KEY" environment variable securely. Never publish your API key in the repository.

4. Run the application

streamlit run app.py
